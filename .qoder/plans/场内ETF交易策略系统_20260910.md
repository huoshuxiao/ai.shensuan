# 场内ETF交易策略系统

> 本文件为系统的权威设计文档，**每次代码更新后须同步更新本文件**。
> 当前状态：全部功能已实现并验证（111 个测试通过）。

## 核心业务逻辑梳理

### 三阶段运行模式
- **盘前 (Pre-Market)**: 9:00 前运行。基于前一日收盘数据，计算因子信号，生成当日交易计划（买/卖/持有/空仓）。
- **盘中 (Intra-Day)**: 9:30-15:00 运行。监控实时行情，在价格触及关键位时发出高抛/低吸信号。
- **盘后 (Post-Market)**: 15:30 后运行。复盘当日交易，更新持仓状态和因子数据，输出当日总结（含账户总资产）。

### 因子体系（对应规则，全部可配置）
| 规则 | 因子化（配置名） | 权重 | 说明 |
|------|--------|------|------|
| 别人贪婪时恐惧 | 市场情绪因子 `sentiment` | 0.20 | 成交量异动 / 大盘涨跌幅，逆向逻辑 |
| 别人恐惧时贪婪 | 超跌反弹因子 `oversold` | 0.25 | RSI超卖 / 偏离均线程度 / 连续下跌天数 |
| 误燥，戒贪 | 仓位控制因子 `position` | 0.15 | 持仓盈亏 / 持有天数 / 止盈止损线 |
| 高抛低吸 | 择时因子 `timing` | 0.20 | 布林带位置 / MACD / KDJ超卖 |
| 防止越低越买 | 趋势保护因子 `downtrend_guard` | 0.20 | MA20/MA60排列、MA60斜率、60日新低（带容差防噪声误判） |
| 没有好标的可空仓 | 综合评分阈值 | - | `score_threshold=60`，低于阈值输出空仓信号 |

- 因子组合通过 `src/config/settings.py` 的 `factor_weights` 字典配置：键为因子名，值为权重；权重 <= 0 即停用该因子。因子类须在 `src/core/strategy.py` 的 `FACTOR_CLASSES` 注册表中注册。

### 标的选择逻辑
1. 从预设ETF池（宽基 + 行业）获取全部候选
2. 对每只ETF计算启用的多因子得分
3. 加权合成综合评分
4. 选评分最高且超过阈值的一只
5. 无达标则空仓

## 关键模块说明

### Task 1: 项目初始化与配置（`src/config/settings.py`）
- **资金**：`initial_capital = 10000.0`（初始资金 1W，买入时校验资金充足，日报输出账户总资产 = 初始资金 + 已实现盈亏 + 浮动盈亏）
- **数据源（可配置）**：`data_sources = ["akshare", "tencent"]`，按顺序尝试，前面优先；`akshare`=东财ETF/新浪指数，`tencent`=腾讯行情
- **标的池（可配置）**：`etf_base_csv` 指向 `data/base/etf_base.csv`（第一列代码、第二列名称）；`etf_candidates` 为参与评分的候选代码列表（默认 17 只）；`wide_base_codes` 为宽基代码集合（其余候选归为行业）
- **因子组合（可配置）**：`factor_weights` 字典（见上表），权重 <= 0 停用
- 其余：评分阈值、仓位上限、止盈止损比例、限频重试参数
- `src/config/etf_pool.py`：从 CSV 加载全市场 ETF 基础表（代码->名称），按 `etf_candidates` 组装候选池；CSV 中不存在的候选代码自动跳过并告警

### Task 2: 数据获取层 (`src/core/data_fetcher.py`)
- 统一接口：`get_etf_daily(code, days)`、`get_etf_realtime(code)`、`get_market_index_daily(symbol)`
- **多数据源回退（按 `settings.data_sources` 配置顺序）**：每个数据源失败/返回空则尝试下一个；实时行情全部失败时降级为最新日线；所有源失败抛 `RuntimeError`
- 数据缓存机制（日线长期、实时10分钟），避免重复请求
- 数据合规：仅用于个人研究，报告标注数据来源与免责声明；请求限频（间隔+随机抖动）与指数退避重试
- 腾讯源解析：K线 `web.ifzq.gtimg.cn`（行格式 [date, open, close, high, low, volume]）；实时 `qt.gtimg.cn`（`~` 分隔：idx3 最新价、idx32 涨跌幅、idx36 成交量手、idx37 成交额万元）

### Task 3: 数据合规与校验 (`src/core/data_validator.py`)
- 字段完整性校验：OHLCV 必需字段、日期升序且无重复、价格非负
- 异常值检测：单日价格跳变（如 > 20%）、成交量异常、停牌/零成交识别
- 缺失数据处理：少量缺失前向填充，缺失过多则该标的本次跳过评分
- 复权检查：统一使用前复权数据，避免除息导致的价格跳空
- 数据不足降级：历史数据条数不足时该ETF不参与选择，绝不输出脏信号

### Task 4: 因子模块 (`src/core/factors/`)
- 输入为经 data_validator 校验后的干净数据
- `base.py`: 定义 `BaseFactor` 抽象基类，统一接口 `calculate(data, context) -> FactorResult`
- `sentiment.py`: 成交量比率（当日/近5日均量）、大盘涨跌幅（上证指数偏离度）；逆向逻辑：放量上涨 -> 恐惧信号，缩量下跌 -> 贪婪信号
- `oversold.py`: RSI(6) < 30 得分高、价格偏离MA20程度、连续下跌天数
- `timing.py`: 布林带位置（接近下轨得分高 -> 低吸）、MACD金叉/死叉、KDJ超卖区域
- `position.py`: 当前持仓盈亏比例、已持有天数、止盈止损触发判断
- `downtrend_guard.py`: 防越低越买——空头排列(MA20<MA60) -20、MA60五日下行 -15、60日新低 -15、多头排列且MA60上行 +15；含容差阈值（0.5%排列容差、0.2%斜率容差）避免横盘噪声误判

### Task 5: 评分与选择 (`src/core/scorer.py`, `src/core/selector.py`)
- `scorer.py`: 对每只ETF执行启用因子计算，加权合成总分
- `selector.py`: 选最高分ETF，与阈值比较，低于阈值返回空仓信号

### Task 6: 策略引擎 (`src/core/strategy.py`)
- `FACTOR_CLASSES` 注册表 + `build_factors()` 按 `settings.factor_weights` 动态构建因子列表
- `run_pre_market` / `run_intra_day` / `run_post_market` 三阶段整合因子评分 + 风控 + 持仓状态
- 输出交易信号：BUY / SELL / HOLD / EMPTY（空仓），包含信号理由文本
- `apply_buy`：资金校验（买入金额不得超过 初始资金 + 累计已实现盈亏），抛 `ValueError` 资金不足
- 盘后计算并输出账户总资产（初始资金 + 已实现盈亏 + 持仓浮动盈亏）

### Task 7: 风控模块 (`src/core/risk.py`)
- 止盈线（如 +5%）、止损线（如 -3%）
- 单次最大仓位比例
- 连续亏损后的冷却期

### Task 8: 三阶段运行入口（`src/runner/`，`main.py` 调用）
- 盘前: 读取前日数据 -> 全池因子计算 -> 生成当日交易计划
- 盘中: 读取实时行情 -> 检查止盈止损/高抛低吸点位 -> 输出盘中信号
- 盘后: 更新持仓状态 -> 记录当日盈亏 -> 输出日终总结（含账户总资产）

### Task 9: 输出模块 (`src/output/`)
- `models.py`: 定义 `TradeSignal`, `DailyReport` 等数据模型
- `reporter.py`: 格式化输出到终端（tabulate表格），同时落盘 **Markdown** 文件：
  - 按日期目录组织：`output/reports/YYYY-MM-DD/`（项目根目录）
  - 交易信号：`signal_{mode}_{HHMMSS}.md`（盘前计划/盘中信号/交易记录）
  - 盘后日报：`daily_report.md`
  - 报告含合规声明（个人研究免责 + 数据来源标注）

### Task 10: 状态持久化 (`src/storage/state.py`)
- 使用JSON文件存储当前持仓（标的、成本价、数量、买入日期、持有天数、累计盈亏、连续亏损次数）
- 文件损坏时按空仓降级处理

### Task 11: 主入口 (`main.py`)
- argparse 支持 `--mode pre|intra|post|backtest` 与 `--action buy|sell`（配合 `--code/--price/--quantity`）
- 回测模式支持 `--start/--end` 指定区间（默认 2026-01-01 ~ 2026-09-12）
- 边界防护：池外代码、无持仓卖出、资金不足均输出友好错误提示，退出码 1

### Task 12: 回测模块 (`src/core/backtest.py`，`src/runner/backtest.py`，`src/output/backtest_report.py`)
- **数据**：拉取全池日线 `backtest_history_days=300` 自然日（含因子预热期，MA60 需 65 根K线）；交易日历以 510300 为准，取 `backtest_start ~ backtest_end` 区间（非交易日自动截止到最后交易日）
- **信号规则与实盘盘前一致**：持仓触发止盈/止损线 -> 收盘价卖出；否则持有不换仓；空仓冷却期禁买；评分最高且 >= 阈值 -> 买入
- **成交模拟**：每日收盘后决策一次、当日收盘价成交；整手（100份）满仓买入；单边佣金 `commission_pct=0.0003`（万3）买卖各扣
- **每日记录**：日期/动作/代码/价格/份额/现金/持仓市值/总资产/当日收益率/累计收益率/回撤/评分/理由
- **汇总指标**：总收益率、年化收益率、最大回撤、累计已实现盈亏、买卖次数、胜率、平均单笔盈/亏
- **输出**：`output/reports/YYYY-MM-DD/backtest/backtest_daily_{start}_{end}.csv`（每日明细）+ `backtest_report_{start}_{end}.md`（汇总+交易明细+每日净值）+ 终端汇总

### Task 13: 测试与验证 (`tests/`，111 个测试)
- 单元测试：因子逻辑（合成行情数据验证已知输入->期望输出）、数据校验边界、风控止盈止损边界、评分排序与空仓阈值
- 数据层测试：数据源解析、回退链路、缓存零网络、数据源配置（只启用单个源/未知源跳过）
- 标的池测试：CSV 解析（代码/名称列）、异常文件（不存在/为空）、候选池组装（缺失代码跳过、分类判定）
- 展示层测试：终端输出格式（含超长行回归保护）、Markdown 落盘路径与日期目录
- 入口测试：main.py 参数校验与边界行为
- 配置测试：因子组合配置（停用/自定义权重）、资金管理（资金不足/总资产计算）
- 回测测试：整手买入与佣金、止盈/止损触发、冷却期禁买、空仓观望、指标一致性（总收益/年化/回撤）、无数据与无交易日异常、报告文件输出（CSV 行数/MD 内容）
- 集成测试：策略端到端（mock 数据源跑通盘前/盘中/盘后全流程）
- 运行：`python3.10 -m pytest tests/`

## 运行方式

```bash
python3.10 main.py --mode pre          # 盘前生成交易计划
python3.10 main.py --mode intra        # 盘中实时监控（止盈止损/评分复核）
python3.10 main.py --mode post         # 盘后复盘（日报：持仓/盈亏/账户总资产）
python3.10 main.py --mode backtest     # 历史回测（默认 2026-01-01 ~ 2026-09-12，初始资金 1W）
python3.10 main.py --mode backtest --start 2026-03-01 --end 2026-09-12  # 自定义区间
python3.10 main.py --mode pre --action buy --code 510300 --price 3.50   # 记录买入
python3.10 main.py --mode post --action sell --price 3.60               # 记录卖出
```
